## 已知的小问题

- **所有 github.io 项目共用一个「来源」。** 你账号下的任何别的 GitHub Pages 网站，理论上都能读到走神本存在浏览器里的数据（念头、目标；API key 默认只留到浏览器关闭）。换成自己的域名之后这个问题就没有了。这是买域名的第二个理由（第一个是 AdSense 不收 github.io）
- 还没有加内容安全策略（CSP）。等域名和广告定下来再加，因为广告脚本需要专门放行，现在加了以后反而容易把广告挡掉
- 手机锁屏后，浏览器会停掉声音；计时照常，回到页面后声音会接着放。想让声音一直不断，需要做成真正的 App，网页做不到
- 同一轮学习只能在一个标签页里进行，另一个标签页会提示「正在另一个标签页里进行」

- 选「不放声音」并且把页面放到后台超过 5 分钟时，浏览器会放慢后台页面的计时器，结束提示可能晚最多一分钟。计时本身是准的
- 数据只在一个浏览器里。换浏览器或清缓存就没了，设置页可以导出备份
- 分类规则会认错，比如「game theory」会被当成想摸鱼。可以在复盘时手动改类型
