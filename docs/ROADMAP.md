# 接下来做什么（给 Emma）

最后更新：2026-11-21（美东时间）。

第一版的代码是 AI 写的。下面这些事按「你亲手做最有价值」排的，每件都写了改哪个文件。做完一件，在 README 的「Who made what」里记一笔。

## 先做：自己用一周

每天用它学一两轮，随手记下别扭的地方。这比任何功能都重要，因为现在还没有一个真人完整用过它。尤其要检查：

- 戴耳机把 10 个场景各听 30 秒。这些声音是代码合成的，写的时候没人听过。难听的告诉 AI 是哪里难听（太尖、太闷、节奏怪），或者直接改 `js/audio.js` 里对应场景的数字
- 专注分和你的真实感受对不对得上

## 适合你亲手改的（从易到难）

| 想做的事 | 改哪里 | 难度 |
|---|---|---|
| 改任何一句文案 | `js/i18n.js`，中英文各一份 | 很容易 |
| 改颜色 | `css/app.css` 最上面 `:root` 里的颜色值 | 很容易 |
| 给念头分类加关键词（比如你常用的词没被认出来） | `js/classify.js` 的 `RULES`，再在 `tests/classify.test.js` 加一行例子，跑 `npm test` | 容易 |
| 改 AI 回答的语气和长度 | `js/prompts.js` | 容易 |
| 调专注分的权重 | `js/score.js` 的 `computeFocusScore`，对应测试在 `tests/score.test.js` | 中等 |
| 加一个新场景 | `js/scenes.js` 加一项（名字、简介、五个特征值、背景颜色），`js/audio.js` 的 `BUILDERS` 里照着 `rain` 写一个同名的 | 中等 |
| 写一篇新的学习方法文章 | 复制 `guides/` 里任意一篇 `.html` 改内容，中文版放 `guides/zh/`，再加进 `js/views/home.js` 的 `GUIDES` 和 `sitemap.xml` | 中等 |

## 已知的小问题

- 选「不放声音」并且把页面放到后台超过 5 分钟时，浏览器会放慢后台页面的计时器，结束提示可能晚最多一分钟。计时本身是准的
- 数据只在一个浏览器里。换浏览器或清缓存就没了，设置页可以导出备份
- 分类规则会认错，比如「game theory」会被当成想摸鱼。可以在复盘时手动改类型
