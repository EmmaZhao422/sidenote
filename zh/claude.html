配合 Claude 使用走神本

如果你平时就在用 Claude，不需要别的东西，就能让记下的念头得到真正的回答。sidenote-coach 这个 skill 会教 Claude 怎么处理它们。它在你自己的 Claude 账号里运行，用的是你自己的额度，所以本站不花钱，你也不用准备 API key。

它能做什么

  • 处理记下的念头。把记下的念头粘贴过去，或者上传备份文件。问题给答案，待办给第一步，担心的事换个更平静的角度看，最后给你一张「接下来十分钟」的小清单。
  • 做每周复盘。根据备份文件告诉你：专注了多久、专注分多少、走神时在想什么、一般在第几分钟走神、在哪个场景里最专注。数字由脚本计算，算法和本站一致。
  • 帮你计划一轮学习，不到一分钟：一个能检查的目标，两三步，一句开始的话。
  • 在对话里替你记念头。没开本站时也能用。在你说「结束」之前，它只回一个对勾，别的什么都不说。

获取 skill

下载 sidenote-coach.zip

一个很小的 ZIP 文件，里面是纯文本的说明和一个很短的 Python 脚本。添加之前可以先在 GitHub 上看完全部内容。

添加到 Claude

  1. 在 Claude 里打开 Customize，再点 Skills。
  2. 点 + 按钮，选 Create skill，再选 Upload a skill。
  3. 选中刚下载的 ZIP 文件，不用解压。
  4. 确认它在列表里是开启状态。

使用 skill 需要在 Claude 的设置里打开「Code execution and file creation」。Claude 的菜单时不时会变，如果这里的步骤和你看到的对不上，以 Claude 官方的 skill 帮助页为准。

怎么用

  • 学完一轮之后：在本站的「念头」页点复制给 Claude，然后粘贴到 Claude 的对话里。
  • 每周复盘：在本站的「设置」页点保存备份文件，把文件上传给 Claude，问一句「我这周学得怎么样？」
  • 开始学习之前：对 Claude 说「帮我计划一轮 45 分钟的学习，内容是第 7 章」。
  • 没开本站的时候：对 Claude 说「我要开始学 25 分钟，先帮我记着冒出来的念头」。

需要知道的

  • 你粘贴或上传的内容，会在你自己的账号下交给 Claude，适用它的隐私条款。本站看不到这些内容。
  • 聊天窗口不会计时，也放不了声音。计时器、场景和图表还是在本站。
  • 走神本是独立的学生项目，与 Claude 的开发公司 Anthropic 没有隶属或合作关系，也未获其认可。
