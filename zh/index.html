走神了？先记下来。

走神本（Sidenote）是一个免费的学习计时器，只多了一个输入框。学习的时候，冒出来的念头用一句话记在里面，然后继续学。这一轮学完，再一条条处理：问题给答案，待办给第一步，担心的事换个更平静的角度看。最后你会看到注意力都去了哪儿。

开始一轮学习

免费，不用注册。记下的内容只存在你自己的浏览器里。

一轮学习是怎么走的

  1. 先花五分钟准备。写下这一轮要做什么，拆成两三步，把已经在脑子里转的事先倒出来，再跟着呼吸两分钟。
  2. 学习时只留一个输入框。一个计时器，一个背景声，一个输入框。念头冒出来，打一行字，回车，它就不占脑子了。
  3. 学完再处理那些念头。计时结束后一条条过一遍，处理完就勾掉。待办可以直接排进下一轮的计划。
  4. 看出规律。总结页会显示你都学了什么、每一轮有多稳、走神时通常在想什么，以及一般在第几分钟开始走神。

还有什么

  • 十种背景声：窗边的雨、海浪、壁炉、林间的风、夏夜、夜行列车、安静的图书馆，以及棕噪音、粉噪音、白噪音。声音是在你的浏览器里现场合成的，不用下载。
  • 找到适合你的声音：打过三次分之后，走神本会告诉你在哪个场景里专注得最好，并推荐相似的场景。
  • 专注分：每一轮一个 0 到 100 的分数，只用来比较你自己的每一轮。记下念头不会扣分。
  • AI 可接可不接：用自己的 API key，或者配合 Claude 使用（怎么用）。不接的时候，内置小助手会给每个念头一个下一步。
